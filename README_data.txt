This folder should normally contain the raw DHS data files used in this analysis:
- NGKR8BFL.DTA (Kids Recode)
- NGIR8BFL.DTA (Individual Recode)

These files are not uploaded to GitHub because DHS microdata cannot be shared 
publicly under the DHS data access agreement.

To reproduce this analysis:
1. Visit https://dhsprogram.com
2. Create a free account
3. Request access to the 2024 Nigeria DHS dataset
4. Access is usually granted within 24-48 hours
5. Download the KR and IR Stata files
6. Place them in this folder before running the script
